# C5 Certification Evidence — Accessibility

Candidate: **1.0.0-rc.6**

## Standard

C5 uses WCAG 2.2 AA as the product-UI baseline and additionally requires the
release checklist's empirical VoiceOver, TalkBack, Windows High Contrast,
browser-zoom, reduced-motion, and larger-text checks.

The Go board is a two-dimensional game surface, so internal board scrolling may
use the WCAG reflow exception where preserving the spatial board is necessary.
Surrounding UI must still reflow at 320 CSS px.

## Why rc.6 exists

C5 found two real accessibility defects in rc.5:

1. secondary/accent/error text tokens could fall below 4.5:1 on card surfaces
   and, more significantly, in the dark color scheme;
2. the SVG Go board opted out of automatic forced-color adjustment without an
   explicit system-color rendering contract.

rc.6 raises the affected token contrast and defines a forced-colors board
palette using system colors.

## Implementation

- AA contrast floor for secondary, accent, and error text across light/dark
  paper surfaces;
- 3:1 focus-indicator contrast floor;
- explicit Windows forced-colors rendering for board surface, grid, stones,
  markers, ownership, teaching highlights, and focus;
- board gradients/shadows removed in forced colors;
- interactive board exposes an `aria-roledescription` in addition to its
  accessible name, instructions, keyboard shortcuts, and live status;
- dedicated C5 production-build Playwright matrix;
- 320 CSS px reflow in Chromium, Firefox, and WebKit;
- larger-text + higher-contrast narrow-layout stress test;
- keyboard-only fresh lesson/board journey;
- keyboard-only independent Play journey;
- forced-colors runtime check;
- reduced-motion runtime check;
- static contrast gate that fails future regressions.

## Automated versus empirical evidence

Automation can prove keyboard event paths, DOM semantics, live-region content,
320px reflow, token contrast, and CSS media-query behavior.

It cannot truthfully certify how VoiceOver or TalkBack speaks the experience,
real Windows High Contrast rendering, or browser chrome at 200–400% zoom.
Those remain explicit manual rows in
`certification/c5-accessibility-checklist.json`.

## Current verdict

**Implementation candidate ready for CI. Full C5 certification remains pending
until the required assistive-technology and real-OS rows are executed.**
